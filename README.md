# opencode config

This is my [opencode](https://github.com/anomalyco/opencode) config.
It is meant to be self-contained and auto-initialises everything on first startup.

## Setup

1. Clone this repository
2. Copy `.env.ovhcloud.apiKey.sample` to `.env.ovhcloud.apiKey` and paste your API key (just the key value)
3. Start opencode
